Terminal idle RPG

Progress Quest,
in the terminal.

pq-cli is a Python terminal port of Progress Quest. Create a character, watch the adventure progress, and keep your save data between sessions.

View source on GitHub Original Progress Quest

Features

  • Faithful port of the original game logic.
  • Colorful curses interface and a minimal basic interface.
  • Local save files with backups.
  • Customizable races, classes, monsters, equipment, spells, and combat text.
  • Import and export compatible Progress Quest character files.

Install

Requires Python 3.10 or newer.

python -m pip install --user pqcli
pqcli

Or run from source:

git clone https://github.com/ArkansasIo/pq-cli.git
cd pq-cli
python -m pip install .
pqcli

Run tests from source

uv sync
uv run pytest
